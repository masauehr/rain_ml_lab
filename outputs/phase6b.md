# Phase 6b（追加実験）: 三角形法・最小二乗法による風の収束量

（`src/run_phase6b.py` が自動生成。2010〜2024年の leave-one-year-out。2025年は使っていない）

- 三角形法: 3地点を通る平面で風を近似し、発散を求める（tri_n=奥・名護・宮城島、tri_c=名護・宮城島・那覇、tri_s=宮城島・糸数・那覇）。
