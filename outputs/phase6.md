# Phase 6（追加実験）: 風の収束量

（`src/run_phase6.py` が自動生成。2010〜2024年の leave-one-year-out。2025年は使っていない）

収束量 = 那覇（南端）と名護（北端）の風の、線方向（那覇→名護）の成分の差から求めた収束（正が収束）。単位 1e-6 /s。線の長さ約51km。風向は16方位・前10分間の平均。特徴量: conv（t時）・conv_d1（1時間の変化）・conv_d2（2時間の変化）・conv_mean（6時〜t の平均）・cross（線に直交する成分の差）・spd_diff（風速差）。
