# notebooks — 動かして学ぶ機械学習

午前の観測から午後の大雨を当てる**実データ**（沖縄・那覇と名護）を使って、機械学習の用語と手法を、**動かしながら**学ぶ7本のノートです。
各ノートは、**キーワード表 → 小さな実験 → 「出力の見方」→ 演習**の順で書いてあります。

> 🔰 **はじめての方へ**: 先に [../GLOSSARY.md](../GLOSSARY.md)（用語集）を読むと、ノートが楽になります。ブートストラップ・PR-AUC・ExtraTrees などを、数字の例で説明しています。

## 各ノートで分かること

| ノート | 実行して分かること |
|---|---|
| 00 | 大雨は100回に3〜4回だけ（那覇の陽性率 約3.5%）。同じ日の3標本は、ほぼ同じ答えになる |
| 01 | 「常に降らない」で正解率は約97%。**正解率は、まれな事象では役に立たない**。ランダム分割で評価すると、点数が甘くなる（0.41対0.09〜0.11） |
| 02 | 木が1本だと弱く、森にすると約2倍になる。ExtraTrees と RandomForest は、ほぼ同等 |
| 03 | シードのばらつきは小さく、**データの偶然のばらつきは約20倍大きい**。差の区間が0をまたぐなら、優劣は言えない。1年だけで評価すると、PR-AUC は約0.04〜0.60とぶれる |
| 04 | impurity は連続値を過大評価する（人工データで確認）。那覇は日照・日射・水蒸気・風、名護は風・時刻と月が効く |
| 05 | 2地点法は、等方的な収束の**約半分**しか拾えない。三角形法・最小二乗法は大きさが合うが、**局地的な風の違い1m/sでノイズが信号を上回る**。実データでは、**どの方法でも予測は良くならなかった**（区間が0をまたぐ） |
| 06 | `class_weight` を使うと、確率が実際より大きく出る（予測0.56に対して実際0.07）。Platt 補正で直るが、Brier スコアは「常に陽性率」とほぼ同じ |

## 収束量の計算を、3行で

1. 風向（16方位）と風速を、**東西成分 u と南北成分 v** に直す（風向は「吹いてくる向き」なので、`u = −風速·sin(向き)`、`v = −風速·cos(向き)`）。
2. **発散 = ∂u/∂x + ∂v/∂y**（東に進むと u がどれだけ増え、北に進むと v がどれだけ増えるか）。**収束 = −発散**。
3. 地点が2つなら**線方向だけ**（2地点法）、3つなら**平面を厳密に通す**（三角形法）、4つ以上なら**最小二乗で平面を当てはめる**。

詳しい説明と、人工の風での検算は、[05](05_convergence.ipynb) にあります。結果の全体は [../outputs/phase6.md](../outputs/phase6.md)（2地点法）・[../outputs/phase6b.md](../outputs/phase6b.md)（三角形法・最小二乗法）。
